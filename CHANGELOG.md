# Changelog

All notable changes to this project will be documented in this file.

## 1.0.0

- Initial release.
- Sidebar footer balance widget: real-time DeepSeek account balance from the official `/user/balance` API.
- Five-day spending chart derived from daily balance snapshots, accumulating from install time.
- Reuses the `DEEPSEEK_API_KEY` credential reference (no extra configuration).
